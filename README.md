### Construimos robótica, software y educación técnica desde México

Somos una empresa de desarrollo tecnológico. Hacemos el **software** con el que damos clase, el **hardware** con el que compiten nuestros estudiantes y las **herramientas** que ponemos en manos de otros docentes. Lo que ves abajo está en uso hoy, no en una presentación.
